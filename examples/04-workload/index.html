Read/write workload

Run a configurable mix of reads and writes. Intermediate observations are checked by range; the final result is deterministic.

Build and check

make
make check
.build/sequential
.build/internal
.build/directive
.build/gnu_tm

Optional arguments: threads operations write_weight read_weight. Defaults: 4 400 1 9. Ranges: 1–8 threads, 1–1,000,000 total operations, weights 0–1,000. The weights must not both be zero. The write count is floor(operations × write_weight / weight_sum).

All four programs check their result explicitly. The checker compares their RESULT lines against the sequential reference and retains complete logs in .build/. The sequential version does not execute OpenMP. Concurrent totals do not depend on scheduling or on the actual team size. No particular conflict count is required.

The internal API requires checking each status and propagating failure. The directive requires -fopenmp -fopenmp-transaction-stm. GNU TM uses __transaction_atomic and libitm, a separate implementation. These are correctness examples, not benchmarks.

Timing protocol, 30-run experiments and plots. TIMING reports elapsed seconds and actual threads.
